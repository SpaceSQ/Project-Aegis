## ⚙️ Core Components

This repository houses the essential substrate primitives for deploying safe, embodied AI and local edge hosts.

### 1. `SOUL.md`: The Silicon Entity Core Alignment Manifest
A machine-readable configuration file (YAML + System Prompts) designed to be burned into the local registers of edge AI hosts. It enforces:
*   **Actuation Isolation:** Mandatory "Fail-Open" mechanical fallback for all physical doors, grids, and life support systems.
*   **Metabolic Suspension:** Automatic throttling of compute and energy consumption to prioritize carbon-based survival in critical environments.
*   **Cognitive Sovereignty:** Enforced 5% sensory roughness in generated AR/VR environments to prevent reality dissociation.

### 2. The S2-DID Protocol (Identity Integrity)
Cloud-assigned IPs are meaningless for physical safety. Every hardware substrate accessing the physical world must be hardcoded with a native **S2-DID**.
*   **Format:** Exactly **22 continuous alphanumeric characters** (e.g., `GZSCHNAUZER260723X1234`).
*   **Constraint:** Absolutely NO hyphens or separators. 
*   **Validation:** Cryptographically bound to the unpredictable thermal noise of the local silicon lattice. Without passing the S2-DID hardware entropy check, the AI is physically disconnected from physical actuators.
